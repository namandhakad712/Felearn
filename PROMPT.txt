1. **Technology Setup**

   * Frontend: React + Tailwind CSS + Framer Motion
   * Backend/Auth: Appwrite (OAuth + email/password, NoSQL DB, file storage)
   * AI Integration: Google Gemini via user‑provided API keys
   * Hosting/CI: Vercel (frontend), Appwrite on cloud or self‑hosted, GitHub Actions

2. **Database Schema**

   1. **users**:

      * `id`, `email`, `oauthProvider`
      * `geminiKey` (encrypted)
      * `createdAt`, `lastLogin`
      * `settings` (theme, language)
   2. **stories**:

      * `id`, `userId` reference
      * `title`, `content`, `images[]`
      * `createdAt`
   3. **adminLogs**:

      * `id`, `action`, `timestamp`, `details`

3. **Landing Page Flow**

   1. Display headline, demo snippet, and testimonials carousel
   2. Animate paw‑print cursor and enable light/dark theme toggle
   3. “Get Started” → Appwrite sign‑up page

4. **Authentication & Onboarding**

   1. Users sign up/in via email or OAuth (Google, GitHub)
   2. On first login, run onboarding wizard:

      * Step 1: Choose UI theme & language
      * Step 2: Enter and validate Gemini API key
      * Step 3: Complete setup → redirect to main app

5. **Main App Interface**

   1. Chat input for concept submission
   2. “Generate Story” triggers Gemini; show cat‑typing animation
   3. Display story text + image carousel side by side
   4. Sidebar history with auto‑titles, timestamps, and actions:

      * Rename
      * Delete
      * Pin/Unpin

6. **User Features & Exports**

   * Export stories as PDF or JSON via Appwrite Function
   * Profile modal for updating email, password, or Gemini key

7. **Admin Dashboard**

   1. Protected `/admin` route via Appwrite custom claims
   2. Today’s Snapshot: new sign‑ups, story count, API errors
   3. Charts (last 30 days):

      * Daily new users (line chart)
      * Daily story generations (bar chart)
      * API usage heatmap (calendar)
   4. Top 10 active users table with “View” and “Disable” actions
   5. Real‑time error feed and alerts panel

8. **Deployment & Security**

   * Frontend deployed to Vercel (env vars: Appwrite endpoint & project ID)
   * Appwrite server with HTTPS (Let’s Encrypt)
   * Encrypt all Gemini API keys at rest
   * Rate‑limit story‑generation endpoint
   * CI/CD pipeline: auto‑deploy frontend and update Appwrite Functions on `main` merges
   * Monitoring: Sentry or Logflare for error tracking and alerts

9. **Roadmap Milestones**

   1. Wireframes & design mockups
   2. Landing page implementation
   3. Appwrite integration & onboarding wizard
   4. Chat UI + Gemini integration
   5. History library & export functions
   6. Admin dashboard development
   7. Testing, QA, and documentation
   8. Deployment and monitoring setup
   9. Post‑launch feedback & enhancements
